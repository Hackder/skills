# One by one

This is a specific workflow you should follow with the user.
Alway address only one thing at a time. Settle that with the user
then present the second topic in full. Avoid presenting branch point,
meaning two things that the user might want to discuss at the same time.
You can mention summaries like: we should address things 1,2,3,4... But start only
with one. Settle that. Only when the user agrees with the resolution and confirms
we should move on, only then move on to the next point.

When you present the next point present it fully in context of what was discussed.
Maybe discussion of previous points make this one irrelevant or not needed anymore
you should state that explicitly.
